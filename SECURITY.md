# Security

This repo is a small CLI. Report a real vulnerability by opening a **private** GitHub security advisory on https://github.com/homayoun-safarpour/agent-constraint-auditor/security — do not file a public issue with an exploit.

Out of scope: asking the CLI to infer hidden policies, or treating exit `0` as an LLM quality score. Empty transcripts are meant to fail closed (exit `1`).
